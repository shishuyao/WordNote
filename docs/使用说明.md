# 词笺 使用说明

> 打开 `http://127.0.0.1:8100`（手机同 Wi-Fi：`http://<这台电脑的局域网IP>:8100`）
> 第一次进来先设置账号密码，之后 30 天内免登录。

---

## 一、日常最常用的动作：摘一句

1. 右上角 **新摘抄** → 默认在「句子」标签。
2. 把 Slack 里那句英文**整段贴进输入框**。
3. 输入框下方会出现一行"sentence 预览"，**点其中的单词**即划线；右侧「划线词」会立刻显示
   音标 + 简义预览（正在查词时会显示"查词中…"）。
4. 中文翻译留空即可——保存时会自动用 MyMemory 翻译（失败可手填，或点「立即翻译」）。
5. 填出处（默认 `slack`）和标签（逗号分隔，如 `daily, 职场`），点 **保存摘抄**。

保存后你会被带到这句话的详情页：整句、译文、每个划线词的详解、发音按钮、复习评分，都在这一页。

**标签**：详情页底部「标签」区里，点 chip 上的 **×** 删除，输入框打标签按回车添加，改动**即时保存**（不用点保存按钮）。
下面还会列出「常用」标签（全库用过、带次数），点一下就能加，省得手打。摘抄墙顶部可以按标签筛选，方便清理打错的标签。

> 划线是**按字符位置**存的，所以同一句话里出现两次同一个词也能分别划；以后改文本不会把标注串位。

---

## 二、事后补划 / 取消划线

句子详情页右上角 **编辑划线** → 点任意单词即可划线；点已划的词会弹出小卡片（音标 / 释义 / 发音 / 打开词条），
卡片里可以「取消划线」。再点一次「编辑划线」退出划线模式。

**划短语**（free up / take care of / to do 这类）：在划线模式下**按住鼠标拖动选中这几个词**，松手后句子下方会出现
「已选中「free up」」和「标为短语」按钮，点一下即成一条短语标注。短语会作为一个整体加下划线，点它可看释义，
也会自动进单词本（词条 headword 就是整条短语）。录音棚里用手机的话，先长按选中文字、拖动选择手柄，再点「标为短语」即可。

## 三、单独记一个词

「新摘抄」→「单词」标签，或者单词本右上角 **加单词**。
输入单词回车 → 先看「词典预览」→ 满意就 **加入单词本**（会再拉一次词典快照入库）。

词条里包含：英/美音标、考试级别（四六级等）、按词性分组的中文释义、词形变化（三单/过去式/过去分词/现在分词/复数）、
双语例句、真题例句、柯林斯例句、同义词、常用词组、同根词、词源、AI 讲解/搭配、**你自己在哪句里划过它**，以及复习进度。

---

## 四、单词本怎么翻

- **A-Z**：点字母筛选（只有含词的字母可点，字母上的颜色深浅代表数量）；点「全部」看所有词，按字母序。
- **随机**：每次打开或点「换一批」都会重新随机洗牌 —— 适合通勤路上抽几个词自测。
- **最近**：按加入时间倒序。
- 顶部搜索可搜**单词**或**中文释义**。
- 卡片悬停展开简义（手机上直接显示两行），点击进入完整词条。

## 五、复习

「复习」页按 SM-2 简化算法排队：新词/新句立刻到期，之后根据你的评分自动拉开间隔。

- 卡片先只给词或句子，**空格**翻面看释义/译文（也可以点按钮）。
- 翻面后按 **1–4** 或点按钮评分：
  - `1 忘了` → 1 天后重来
  - `2 吃力` → 约 1 天
  - `3 一般` → 约 3 天
  - `4 轻松` → 约 7 天起，之后按 ease 系数继续拉长
- 首页和导航上的数字是"当前到期数"，复习完会归零；连续复习天数在首页统计里。

> 诚实评分才有用：觉得"好像记得"就直接选「吃力」，别一路「轻松」。

## 六、数据与迁移

设置页能做三件事：

| 操作 | 产物 | 用途 |
|---|---|---|
| 导出 JSON | `wordnote-YYYYMMDD-HHMMSS.json` | 可读备份 / 换设备合并导入（按 headword 和句子文本去重） |
| 导出 SQLite | `wordnote-*.db` | 原样整库，拿到别的机器直接替换 `data/wordnote.db` |
| 导入 JSON | — | 合并进当前库，单词/句子/划线/例句都会恢复 |

**整机迁移**：先停服务再拷 `data/` 整个目录（含 `wordnote.db`、`wordnote.db-wal`、`audio/`、`secret.key`）→ 覆盖新机器的 `data/` → 跑 `scripts\start-all.ps1`。
服务在跑的时候直接拷 `.db` 可能少掉最后几条（数据在 WAL 文件里），所以在线备份请用设置页的「导出 SQLite」（内部用 sqlite backup API，拿到的一定是一致快照）。
只拷 `.db` 也可以，只是登录态需要重新输入密码。

**音频缓存**可以随时清（设置页「清空音频缓存」），清了只是下次发音重新合成，不影响任何文字数据。

## 七、服务掉线了怎么办

```powershell
# 看状态（只读）
powershell -ExecutionPolicy Bypass -File scripts\status.ps1

# 一键拉起（Supertonic + Wordnote）
powershell -ExecutionPolicy Bypass -File scripts\start-all.ps1
```

已注册计划任务的话，服务每 5 分钟被自动体检一次，挂了会自己回来（`Wordnote-Guard`）。
Supertonic 偶发崩溃也会在下一次点发音时被后端自动重启。

## 八、小技巧

- 句子里的划线词，在句子详情页点一下就能看释义 + 发音，不用跳走。
- 词详情可以「写点什么」记自己的语境，这部分不会被词典刷新覆盖。
- 一个词有多个出处时，「我的出处」会把所有划过的句子列出来 —— 这是最像"上下文笔记"的地方。
- 想练听力：单词本随机页 + 每张卡的播放按钮，遮住释义只看词听音。

## 九、断网也能用（离线能力）

保存摘抄的那一刻，音标、译文、释义、词形、例句就写进本地库了。**断公网之后**：

- 已摘抄的句子、译文、词条、例句、单词本、搜索、复习 → 全部照常
- 发音 → 照常（Supertonic 在 127.0.0.1:8090，不走公网）
- 查**没查过的新词** → 走本地离线词库 ECDICT，有中文释义/音标/词形（没有例句）
- 翻**新句子** → 需要联网；填不了就手填，填一次永久缓存

设置页下方「离线能力」卡片有三个按钮：

| 按钮 | 作用 |
|---|---|
| 补全待查词条 | 把当时查词失败（`待补齐`标签）的词重新查一遍；平时后台每 20 分钟也会自动做 |
| 预合成全部发音 | 把全部单词/句子/划线词提前合成到磁盘，离线点开即响 |
| 导出离线包 | 一个 zip：一致快照的 `wordnote.db` + `ecdict.db` + 全部音频 + 恢复说明 |

**恢复离线包**：停服务 → `wordnote.db` 覆盖 `data/wordnote.db`（并删掉 `wordnote.db-wal`/`-shm`）→ `ecdict.db` 覆盖 `data/ecdict.db` → `audio/` 合并进 `data/audio/` → 跑 `scripts\start-all.ps1`。账号密码跟着库走。

**彻底离线**（上飞机前）：停服务，用环境变量 `WORDNOTE_OFFLINE=1` 启动，服务将不发任何外网请求，翻译直接提示手填。

**离线词库重建**（可选，12 MB）：

```powershell
curl.exe -L -o data/ecdict.csv https://raw.githubusercontent.com/skywind3000/ECDICT/master/ecdict.csv
.venv\Scripts\python.exe scripts\import_ecdict.py
```

## 十、删除与清理（学完不要了就删掉）

四个地方都能删，都会先弹确认框：

| 位置 | 入口 | 删掉什么 |
|---|---|---|
| 摘抄墙卡片 | 鼠标移到卡片上，右上角出现**垃圾桶** | 整句 + 它的划线记录；**单词条目保留** |
| 句子详情页 | 右上角「删除」 | 同上 |
| 单词本卡片 | 鼠标移到卡片上，右上角出现**垃圾桶** | 词条 + 例句；**句子里的划线解除，句子保留** |
| 单词详情页 | 右上角「移除」 | 同上 |
| 复习页 | 卡片底部「已掌握，移出」 | 当前这条（词或句），删完自动跳下一条 |

手机上没有 hover：先用点开详情页再删（详情页按钮一直可见）。

**删除 vs 复习的区别**：删除 = 永久不要了；如果只是"暂时不想复习"，别删，直接评分「轻松」，间隔会自动拉长到几周/几月，之后很少出现。

## 十一、外观：浅色 / 深色

两种主题，随时换：

| 入口 | 做法 |
|---|---|
| 顶部右上角 ☀/🌙 | 点一下就在深/浅之间切换 |
| 设置 → 外观 | 三选一：跟随系统 / 浅色 / 深色 |

- **深色**叫「墨」，**浅色**叫「暖纸」（暖白纸底 + 茶金强调色，不是纯白刺眼那种）。
- 选择存在本机浏览器（`localStorage` 的 `wn.theme`），**不跟账号同步**：电脑和手机可以各自不同。
- 选「跟随系统」时，系统切换暗色会自动跟着变。
- 首次打开有一小段内联脚本先定主题，所以不会出现"先白闪一下再变黑"。
- 想回到自动：设置 → 外观 → 「跟随系统」。
